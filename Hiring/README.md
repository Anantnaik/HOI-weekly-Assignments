# AI Hiring Pipeline

An automated hiring workflow built with **n8n, Gemini, Google Sheets,
and Gmail**.

## What it does

-   Reads candidate resumes and applications
-   Scores candidates from **0--100** using Gemini
-   Matches candidates to open roles
-   Ranks and shortlists the best candidates
-   Finds strong candidates from the existing candidate pool
-   Sends the hiring team candidate summaries and interview questions
-   Generates candidate emails based on interview feedback
-   Logs hiring activity in Google Sheets

## Workflow

**Applications → Resume Screening → AI Scoring → Candidate Matching →
Shortlist → Hiring Team Email → Interview → Outcome Email**

## Tech Stack

-   n8n
-   Google Gemini
-   Google Sheets
-   Gmail

## Purpose

Reduce repetitive manual work in recruitment and help hiring teams find
the right candidates faster.
